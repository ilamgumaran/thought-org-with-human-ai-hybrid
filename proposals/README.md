# Proposals

Strategic proposals for applying the HIO Framework to real organizational contexts.

## Two Paths

| Path | Document | Context |
|---|---|---|
| **Migration** | [migration-proposal-v1.md](migration-proposal-v1.md) | Transitioning an existing 30-person engineering org from traditional scrum/agile to HIO. Includes role-by-role migration, industry research, risk management |
| **Greenfield** | [greenfield-hio-org.md](greenfield-hio-org.md) | Building a multi-billion dollar engineering org from scratch using HIO principles from Day 1. Tech-centered retail business unit. Seed to enterprise scale |

## How These Relate

- **Migration** is for: You have an existing team worth developing. The culture exists, the skills exist, but the model needs transformation
- **Greenfield** is for: You have an opportunity to build from scratch. Every hire, every system, every practice can be designed for HIO from Day 1

Both are grounded in:
- [The HIO Framework](../framework.md) — the four pillars
- [Reference Library](../reference/) — structured knowledge from external sources
- [Industry Research](migration-proposal-v1.md#4-industry-research--what-weve-learned-from-others) — 30+ sources on what's working and failing (2024-2026)
